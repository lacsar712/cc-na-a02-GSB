# 航标灯光巡检台

每座灯先建台账卡（灯号、所在水道、标称坎德拉），没有卡就不许挂巡检。登记航标实测光强和方位偏差时只能挑选已建灯号，要求光强取卡上的标称坎德拉，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可建卡、可登记 |
| watch | watch123456 | 只读，可翻开台账卡看历次实测 |

## 启动

```bash
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，顶栏进「灯标台账」能看到 LH-01、LH-09 的卡；巡检记录里 LH-01 合格、LH-09 不合格。
2. 先给 LH-18 建卡，再登一条实测光强够、方位偏差近乎为零的记录，结论合格；从灯标台账翻开 LH-18 的卡，能点进这条实测。
3. 登记从未建卡的灯号，表单停住并提示缺卡原因。
4. 换 watch 登录，没有登记和建卡入口；能翻开台账卡看历次实测；直接提交登记或建卡会被拒绝。
