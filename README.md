# 航标灯光巡检台

先给每座灯建立台账卡（灯号、所在水道、标称坎德拉），没有卡的灯号不许挂巡检。登记实测时只能从已建卡的灯号中挑选，服务端当场按卡上标称光强给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可建卡、可登记 |
| watch | watch123456 | 只读，可翻卡查看历次实测 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，顶栏进入「灯标台账」，已有 LH-01、LH-09、LH-18 三张卡。
2. 翻开 LH-18 的卡，能看到一条亮度达标、偏角近零的合格实测，并可点进该实测详情。
3. 到登记页：灯号只能从下拉框挑选已建卡灯号；手填一个从未建卡的灯号（如 LH-99）提交，表单停住并显示缺卡原因，不产生记录。
4. 选 LH-18 登记一条实测光强低于标称的记录，结论为光强不足，该记录挂回 LH-18 卡下。
5. 换 watch 登录：可翻开台账卡查看历次实测，但没有建卡和登记入口，直接 POST 对应地址会被拒绝（403）。
